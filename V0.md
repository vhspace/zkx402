# v0 — zkx402 UI instructions

These notes are for **v0** (Vercel’s UI/code generator) working in this repo.

## Where the UI lives

- Next.js App Router client: `apps/demo/client/`
- Primary pages: `apps/demo/client/app/*` (see `home/`, `demo/`, `producer/`, `verify/`)
- Shared UI/components: `apps/demo/client/components/*`

## Styling system

- Tailwind is configured in `apps/demo/client/tailwind.config.ts`.
- Prefer Tailwind utility classes over bespoke CSS.
- Keep `apps/demo/client/app/globals.css` minimal.

## Commands

Install (repo root):

```bash
corepack enable
pnpm install --ignore-scripts
```

Run the Next.js client:

```bash
pnpm run dev:client
```

Build (CI parity):

```bash
pnpm --filter zkx402-client build
```

## Guardrails

- Do **not** change payment/proof logic in `packages/x402-zkx402/` unless explicitly requested.
- Avoid hardcoded absolute paths like `/workspaces/...`.
- If you add UI that depends on env vars, ensure Preview deployments fail **gracefully** (visible error, not a hard crash).
