## Layout

- `packages/x402-zkx402/` — production middleware (proof-aware pricing/access control)
- `apps/demo/server/` — Express API server with the x402 + proof-gating config
- `apps/demo/client/` — Next.js client
- `apps/demo/local-chain/` — deterministic local E2E (`node run-e2e-test.js`)
- `apps/demo/contracts/` — Foundry contracts

## Key behavior

- Hard proof-gating via `config.extra.requiredClaims` (or `config.extra.accessControl`)
  plus `proofPolicy`: quote mode still returns `402`; paid requests return `403`
  when required claims fail.
- The `X-PAYMENT` header must match the **`x402`** npm package schema.

## Role in unification

- Hosts `docs/unify/` (architecture, license matrix) and `docs/repos/` notes.
- Import target for eXpress402 (channels rail, mcp-server-kit slice) and goldenmcp
  (eval-engine, attestation, discovery) per [`../unify/architecture.md`](../unify/architecture.md).
